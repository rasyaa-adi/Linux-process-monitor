
LINUX PROCESS MONITOR

Tentang Project:
Linux Process Monitor adalah alat sederhana berbasis Bash untuk belajar memantau proses pada sistem linux. Project ini saya buat sebagai latihan dasar Linux dan Cybersecurity.

fitur:
     Menampilkan proses milik pengguna (user) yang aktif.
     Menampilkan PID, PPID, penggunaan CPU, penggunaan Memori, dan status proses.
     Mencari proses berdasarkan nama.
     Menyimpan hasil pemantauan dan pencarian ke file laporan.
     Membuat nama laporan berdasarkan tanggal dan waktu.

Teknologi:
     Linux Ubuntu
     Bash shell
     ps
     pgrep
     date
     tee

Cara Menjalankan:
1. Buka terminal (Ctrl+Alt+t) pada folder project.
2. Jalankan:
   bash monitor.sh
3. Pilih menu:
   (1/2): 
   1) untuk menampilkan semua proses.
   2) untuk mencari proses berdasarkan nama.

Lokasi Laporan:
Laporan disimpan di folder reports/.

Tujuan Project:
Project ini membantu memahami proses Linux, PID, PPID, penggunaan CPU, Memori, pencarian proses, serta belajar dasar scripting Bash.

Catatan:
Project ini saya buat sebagai acuan pembelajaran dan pemantauan proses pada sistem miliik sendiri atau sistem yang pengunaannya telah diizinkan.
