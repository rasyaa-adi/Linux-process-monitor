</p>📌 About

Linux Process Monitor is a beginner-friendly Bash project created to practice Linux system administration and foundational cybersecurity skills.

It provides a simple menu for viewing processes owned by the current user and searching for processes by name.

✨ Features

- Display processes owned by the current user.
- Show PID, PPID, CPU usage, memory usage, process status, and command.
- Search for a process by its exact name.
- Save search results to timestamped report files.
- Use a simple interactive terminal menu.

🛠️ Built With

- Bash — scripting and automation
- Linux — operating system environment
- Git and GitHub — version control and project hosting

🚀 Getting Started

Prerequisites

- A Linux system
- Bash
- "ps" and "pgrep" utilities

Installation

Clone the repository:

git clone https://github.com/rasyaa-adi/Linux-process-monitor.git

Enter the project directory:

cd Linux-process-monitor

Make the script executable:

chmod +x monitor.sh

Run the script:

./monitor.sh
